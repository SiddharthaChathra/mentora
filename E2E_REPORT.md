## Scoping matrix
Generated by `tests/rls/matrix.test.ts` (real signed-in clients, never the service role): 10 actors (P, HOD_CSE, HOD_ECE, FORMER_HOD, SUSPENDED_HOD, M_CSE_1, M_ECE_1, A1, B1, anon) × 10 student-data tables × CSE/ECE/ME, `seen/total` per cell. Full table: `test-results/rls-matrix.md` (regenerated each run). Summary:

| Actor | CSE | ECE | ME |
|---|---|---|---|
| P (Principal) | all rows (SHARED notes only) | all | all |
| HOD_CSE | all rows | 0 | 0 |
| HOD_ECE | 0 | all rows | 0 |
| FORMER_HOD, SUSPENDED_HOD, anon | 0 | 0 | 0 |
| M_CSE_1 / M_ECE_1 | own active mentees only | own active mentees only | 0 |
| A1 / B1 | self only | self only | 0 |

Also asserted: Principal never sees PRIVATE_MENTOR (HOD does, own branch); counts/head requests return in-scope totals only; ended/suspended HODs see no other user, audit, transfer or follow-up rows; ME (no HOD) visible only to P and ME people; HOD audit rows = own branch only.
Writes: HOD_CSE cannot update an ECE semester, cannot move a CSE row into ECE (trigger re-derives the branch), cannot add an ECE subject, cannot assign across branches (RPC refused; direct insert → `MB_CROSS_BRANCH`); Principal cannot update records/profiles, insert notes, assign or review corrections; HODs cannot rename branches or appoint HODs. Storage: ECE resource file denied to HOD_CSE and M_CSE_1, readable by P and HOD_ECE.
Policy lint (`tests/rls/policy-lint.test.ts`): no `is_hod()` policy without a branch condition; RLS on every public table; no Principal write policy on student-data tables. Inventory: `tests/rls/policy-inventory.md`.

## Revocation
- Principal appoints M_ECE_2 as ECE head → HOD_ECE's very next query returns 0 ECE rows, the new head sees ECE; restored.
- UI: Principal ends the ECE appointment → HOD_ECE's next page is "Your HOD access has ended"; re-appointed through the UI.
- Transfer T1 CSE → ECE (HOD request → Principal approve, also via the UI): student moved, active assignment ended, HOD_CSE and the old mentor see 0 of T1's rows (profile URL → 404), HOD_ECE sees T1's full history, transfer audited; restored with "Move a student".
- Archiving a branch with active students → refused with a clear message.

## Failures found by the loop (root cause → fix)
| Spec | Symptom | Root cause | Fix |
|---|---|---|---|
| matrix "ended or suspended HODs" | FORMER_HOD could read the Principal's user row | "any active account may read Principal" | migration 017 `app.has_scope()` |
| e2e Principal journey | every student profile showed "not found" | new `departments.created_by → users` FK made the `users → departments(name)` embed ambiguous | `departments!users_department_id_fkey(name)` |
| e2e attack | out-of-scope profile returned 200 with the 404 UI | `notFound()` inside a streamed `loading.tsx` boundary | `proxy.ts` RLS-scoped check → real 404 |
| unit admin-guards | `manageable()` touched the admin client before the role check | order of checks | role check first |
| self-signup RLS + smoke | sign-up with a non-USN email now refused | new USN rule | tests use USN emails; form hint added |
| crawl principal @390 | header + chart header overflow | two switchers in the header; chart actions don't wrap | branch sheet on phones; ChartFrame actions wrap; shorter toggle labels |
| RLS suites (run 1) | demo password used for a fixture student | fixture gave T1 the demo mentor | T1 → M_CSE_2; tests pick demo mentees by email |
| perf | college pages 8–12 s | per-row SECURITY DEFINER calls in read policies + full roster loads | migration 018 + slim/parallel loads + cached digests |
